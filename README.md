# Leo Club of Kathmandu Laligurans - Website

A modern, high-performance website for the Leo Club of Kathmandu Laligurans, built with a focus on premium aesthetics, storytelling, and universal accessibility.

## 🌟 Key Features

- **Laligurans Preloader**: A realistic, multi-layered flower-blooming animation (rhododendron) that sets the stage for the club's identity.
- **Premium Parallax Design**: Multi-layered background and element parallax effects for a sense of depth and immersion.
- **Interactive 3D Cards**: Activity cards that respond to mouse movement (hover) on desktop for an engaging experience.
- **Dynamic Scroll Animations**: Elements reveal themselves intelligently as you scroll, with staggered entries for grid layouts.
- **Horizontal Blog Carousel**: A mobile-optimized horizontal scroll for blog stories with "center-focus" scaling effects.

## 📱 Mobile Responsiveness & Compatibility

The website is engineered to be **universal**, meaning it looks and works perfectly on everything from a 4K monitor to an iPhone SE (320px width).

- **Fluid Typography**: Uses `clamp()` functions to ensure text scales smoothly between mobile and desktop without breaking layouts.
- **Adaptive Grids**: Automatically switches between multi-column grids (desktop) and single-column or horizontal carousels (mobile).
- **Responsive Media**: Images use `object-fit: cover` and proper container constraints to maintain aspect ratios on all screens.
- **Touch-Friendly Navigation**: A dedicated mobile menu system with smooth transitions and easy-to-tap targets.
- **Performance Optimized**: Uses lightweight CSS transitions and Intersection Observer for efficient animations that don't drain mobile batteries.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **Vanilla CSS3**: Custom design system with modern properties like CSS Variables, Flexbox, Grid, and `backdrop-filter`.
- **Vanilla JavaScript**: Lightweight logic for animations, parallax, and interactive components (no heavy libraries like jQuery or GSAP).

## 🚀 Deployment

The site is optimized for static hosting (GitHub Pages, Netlify, Vercel). Simply upload the files and it's ready to go.
